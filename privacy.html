개인정보 처리 안내

시행일: 2026년 10월 24일

1. 처리하는 정보

TikTok 연결 시 계정 식별자(open_id), 표시 이름(display_name), 액세스 토큰과 갱신 토큰을 처리합니다. 권한은 기본 프로필(user.info.basic)과 초안 영상 전송(video.upload)입니다. 사용자가 영상을 선택하고 전송에 동의한 경우, 그 영상 파일을 TikTok으로 전송합니다. 영상은 TikTok 받은 편지함에서 검토하고 게시를 마칠 수 있도록 초안으로 전달됩니다.

2. 이용 목적

계정 연결 상태와 기본 프로필 표시, 토큰 갱신, 그리고 사용자가 명시적으로 선택하고 동의한 영상의 TikTok 초안 전송에만 사용합니다. 이 프로그램은 사용자의 별도 동의 없이 영상을 전송하거나 게시하지 않습니다.

3. 저장 위치와 보관

현재 실험 버전은 OAuth 토큰을 프로그램이 실행되는 로컬 컴퓨터의 설정 폴더에 저장합니다. 사용자가 선택한 영상 파일은 별도 업로더 서버에 저장하지 않고 TikTok API로 직접 전송합니다. 전송 후 TikTok의 보관·처리 방식은 TikTok 정책을 따릅니다. 로컬 컴퓨터에 접근할 수 있는 사람은 토큰 파일에 접근할 수 있으므로 기기 보안을 유지해야 합니다.

4. 외부 제공

로그인, 프로필 확인, 토큰 갱신·폐기 및 동의한 영상의 초안 전송을 위해 TikTok 공식 API와 통신합니다. 이 프로그램은 토큰이나 프로필 정보를 다른 제3자에게 제공하지 않습니다.

5. 삭제 및 연결 해제

앱에서 TikTok 연결 해제를 실행하면 로컬 토큰 파일을 삭제하고 가능한 경우 TikTok에 토큰 폐기를 요청합니다. 연결 해제는 TikTok 계정이나 TikTok에 이미 전송한 초안을 삭제하지 않습니다. 초안은 TikTok 앱에서 관리해 주세요.

6. 현재 서비스 범위

현재 버전은 로컬 컴퓨터에서 실행하는 실험용 앱이며, 공개 회원가입이나 별도 고객지원 창구를 제공하지 않습니다. TikTok 초안 전송은 개발자 앱의 권한 및 TikTok의 심사 상태에 따라 이용 가능 여부가 달라질 수 있습니다.
